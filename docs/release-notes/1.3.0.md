A release with a new name, Gex 64 on the game's player and loops that repeat as the game plays them. ultrasf2, formerly realsf2, converts the music of Nintendo 64 games to MIDI, SoundFont 2 and SFZ files.

## Downloads

| File | Contents |
|---|---|
| `ultrasf2-1.3.0-win-x64.zip` | Windows x64 executable, `README.md`, `LICENSE` and `THIRD-PARTY-NOTICES.md` |

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more images or ROM sets onto `ultrasf2.exe`. You can also use a terminal. `ultrasf2 --help` lists the options. Output goes in a folder beside each image or set.

For macOS, follow the build instructions in the README. macOS builds include `Ultrasf2.app`. Drop images or ROM sets onto the app in Finder to convert them.

## Changes

- **The name.** realsf2 is now ultrasf2. The program, the macOS app and the download take the new name. So does the output folder, `<image name>_ultrasf2`. The comments in the files that the program writes name ultrasf2 too.
- **Gex 64: Enter the Gecko.** The songs now play by the rules of the N64 Music Tools' later player, as in the game. 1.2.0 played them by the rules of the early player. Envelopes with a speed above 1 now run at the game's times. Each channel keeps one voice, and a new note cuts the last one. The loud notes of the Toon TV songs stop at the player's volume stop, as in the game.
- **Gex 64's loops.** The game plays most pitch bends only in a song's first pass. The files now do the same. Where a channel's second pass differs from its first, the loop is now the second pass, and the first plays once before it.
- **Loops in the MIDI games.** In the games that play MIDI sequences, such as GoldenEye 007 and Hey You, Pikachu!, a player that loops a file on its markers now plays every repeat as the game plays the passes after the first. The game keeps a channel's program, volume, pan, send, bend and tempo from one pass to the next. Where the first pass starts with other values than the later passes, the loop is now the second pass, and the first plays once before it. Where the game sets a value again at the start of each pass, the file sends it again at the loop's start.
- **Loops from the first tick.** In GoldenEye 007, a loop that starts at the first tick no longer sets a channel's starting volume and pan again on each repeat. A note held across the jump to the loop's start keeps the volume and pan of the loop's end, as in the game.
- **Pieces that end.** A song whose loop plays no note after its last note has ended now ends with its last sound, without loop markers. A player that loops no longer plays silence for ever. Empty sequences end at once.
- **Reverb.** In the games that play their music on the SDK's sequence player, such as GoldenEye 007, each channel now starts with CC91 0 until its sequence sets a send. In Super Real Mahjong VS, whose synthesizer has no effect, every channel stays at CC91 0. A player that follows General MIDI 2, such as BASSMIDI, gave a channel without CC91 its default reverb send of 40. The game plays no such send. An image without a profile now writes the sends that its sequences set.
- **File names.** ultrasf2 no longer names songs from tables in its code. Each file is named `Sequence 0xNN`. Where a game plays a sequence in more than one way, the name gives the settings of each way in parentheses, such as `Sequence 0x02 (port 2 = 1)` or `Sequence 0x05 (rate 0.798)`. Super Real Mahjong VS's stereo songs end with `(set 2)`. Mario Tennis keeps the song names in the game's data. The music in the files doesn't change.
- **`--no-resampler-filter`.** By default, ultrasf2 writes each wave through a filter that matches the console's resampler. With the new option, the samples contain the waves as the game decodes them. The MIDI files and the SFZ text don't change.
- **The report.** For Chameleon Twist 2, GoldenEye 007 and Hey You, Pikachu!, ultrasf2 lists the notes whose decays and releases it fits to the top 20 dB of the game's straight ramps.
- **Aleck64 sets with several games.** A ZIP archive or a folder with the chips of more than one game now gives a warning. ultrasf2 converts one of the games, and the warning names the others. Put each game in a folder or an archive of its own.
- **The libraries.** ultrasf2 now builds on ultralib 2.0.0, ntdlib 7.0.0, xsflib 1.12.0 and seqlib 1.5.0. ultralib contains the N64 code that used to be in ntdlib.
- **The documents.** `THIRD-PARTY-NOTICES.md` now lists puff, the DEFLATE decoder from ntdlib that is compiled into ultrasf2, with its zlib licence. The README now says that Pokémon Stadium 2 plays four songs faster, that the SDK's synthesizer ramps in decibels where three games' libraries ramp in straight lines of amplitude, and which games keep one voice for each channel. It also says that Gex 64 plays songs of the Music Tools' early form on the later player.
